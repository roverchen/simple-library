## 四、已知限制

- 成員以「班級＋姓名」辨識，未另存學號／員工編號；同班同名需人工留意。
- 借閱紀錄提供年度／學年篩選，尚未提供自訂起訖日期。
- 預約僅限「借出中」的書，且為「單筆待履行」：不保留書籍、沒有多人排隊順序，書歸還後仍可能被他人先借走。
- 相機掃碼僅能在 `localhost` 或 HTTPS 使用；區網 HTTP 請用條碼槍。
- PDF 內嵌中文字型，單檔約 3 MB；一般列印與留存足夠。
- 手機版不含班級成員管理與標籤列印。

## 五、驗收指令（工程師用）

```bash
python3 -m py_compile server.py pdf_report.py
python3 - <<'PY'
import re, subprocess, tempfile, os
for f in ['index.html', 'mobile.html']:
    html = open(f, encoding='utf-8').read()
    for i, sc in enumerate(re.findall(r'<script(?![^>]*src)[^>]*>(.*?)</script>', html, re.S)):
        if not sc.strip():
            continue
        with tempfile.NamedTemporaryFile('w', suffix='.js', delete=False, encoding='utf-8') as t:
            t.write(sc); tmp = t.name
        r = subprocess.run(['node', '--check', tmp], capture_output=True, text=True)
        os.unlink(tmp)
        assert r.returncode == 0, (f, i, r.stderr)
print('JS OK')
PY
```

PDF 端點需先登入（Cookie），例如：

```bash
curl -c cookie.txt -X POST http://127.0.0.1:8000/api/login \
  -H 'Content-Type: application/json' -d '{"password":"1234"}'
curl -b cookie.txt -o inventory.pdf \
  'http://127.0.0.1:8000/api/report/inventory.pdf?kind=all'
```
